note:

Don’t just use the latest for everything. The code has two compatibility risks:

pandas 3.x breaks this line: df['TotalCharges'].fillna(..., inplace=True). Pandas 3 uses Copy-on-Write, so this chained in-place call no longer modifies df. The NaNs stay, and Logistic Regression then crashes on them. The fix that works on any version is:
python
   df['TotalCharges'] = df['TotalCharges'].fillna(df['TotalCharges'].median())

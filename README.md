## 🚀 Getting Started: Telco customer churn analyis (ML project)
## Interactive Streamlit Web App

### Prerequisites
Install packages:
* pip install streamlit pandas numpy matplotlib seaborn plotly scikit-learn kagglehub

### Installation

1.  **save the code as churn_app.py**
2. **run the app:**
    ```bash
    streamlit run churn_app.py
    ``` 
3.  **Open your browser to http://localhost:8501**
